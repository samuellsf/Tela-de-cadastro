# ⚡ Tela de Cadastro e Recuperação de Senha

Um projeto moderno de páginas de autenticação (Criar Conta e Recuperar Senha) desenvolvido com um design elegante em tema escuro (*dark mode*), efeitos visuais de destaque, campos interativos e ícones.

🔗 **Acesse o projeto online:** [https://samuellsf.github.io/Tela-de-cadastro/](https://samuellsf.github.io/Tela-de-cadastro/)

---

## 🎨 Funcionalidades e Design
* **Tema Escuro Moderno:** Cores cuidadosamente selecionadas (tons de azul escuro e roxo) inspiradas nas melhores tendências de UI/UX atuais.
* **Campos Interativos:** Inputs com ícones integrados (utilizando FontAwesome), indicador visual de foco e suporte a *autofill* estilizado.
* **Força da Senha:** Estrutura pronta para exibir barras indicadoras de segurança da palavra-passe.
* **Autenticação Social:** Botões estilizados para login rápido com Google e GitHub.
* **Design Responsivo:** Adaptado para diferentes tamanhos de ecrã (telemóveis, tablets e computadores).

---

## 🛠️ Tecnologias Utilizadas
Este projeto foi construído utilizando as seguintes tecnologias e ferramentas:
* **HTML5** (Estruturação semântica)
* **CSS3** (Estilização personalizada, variáveis CSS e gradientes)
* **Tailwind CSS** (Framework utilitário para agilizar o layout)
* **FontAwesome** (Biblioteca de ícones)
* **GitHub Pages** (Hospedagem e publicação gratuita)
